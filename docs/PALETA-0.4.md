# Icatya 0.4.0 — identidade e cores

Paleta escura neutra baseada nas áreas planas da captura de referência. O destaque azul-violeta fica reservado às ações principais; os cinzas separam a navegação, o conteúdo e os controles.

| Cor | Aplicação |
| --- | --- |
| `#121214` | Barra lateral e título da janela |
| `#1A1A1E` | Fundo principal |
| `#202024` | Painéis |
| `#17171A` | Campos de entrada |
| `#29292D` / `#2C2C30` | Seleção e passagem do mouse |
| `#333338` | Bordas discretas |
| `#EFEFF1` | Texto principal |
| `#ABACB2` / `#96979E` | Textos secundários |
| `#5865F2` | Botões principais e foco |

Verde, amarelo e vermelho ficam disponíveis para mensagens de estado. Os tons em cinza evitam que toda a interface dispute atenção com a transmissão. A diferença sutil de luminosidade cria profundidade sem precisar de sombras pesadas.

O tema está centralizado em `src/Icatya/Themes/DarkTheme.xaml`. A barra nativa do Windows segue as cores escuras quando o sistema oferece suporte.

Nome exibido: Icatya. Solução: icatyalive.slnx. Executável: Icatya.exe. O iniciador antigo continua funcionando como atalho de compatibilidade. As licenças de terceiros e os identificadores internos de conexão existentes foram preservados.

A conexão permanece por convite e resposta, sem áudio. Salas com código de seis letras, retorno à última sala, transmissões simultâneas, barra lateral arrastável/recolhível e áudio seletivo por aplicativo são próximos requisitos, ainda não implementados.
