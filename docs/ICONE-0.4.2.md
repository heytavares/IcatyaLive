# Icatya 0.4.2 — ícone

Adicionado o ícone fornecido pelo autor, preservando a imagem PNG original e sua transparência. O executável e as janelas usam o mesmo ícone, com representações de 16, 24, 32, 48, 64, 128 e 256 pixels para diferentes tamanhos e escalas do Windows.

Original: `src/Icatya/Assets/logo-icatya.png`.
Ícone Windows: `src/Icatya/Assets/Icatya.ico`.
Para regenerar o ICO após substituir o PNG, execute `scripts/Atualizar-Icone.ps1`.

Mantém as melhorias de desempenho da 0.4.1. Mudança de identidade visual, sem alterações na transmissão. Publicação Release Windows x64 compilada sem erros; o ícone foi extraído do executável publicado para conferir a incorporação correta.
